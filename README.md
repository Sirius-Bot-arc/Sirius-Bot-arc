## How I work

I learn best by building.

I make something → test it → break it → investigate what happened → fix it → probably break it again.

The goal isn't just to make something that works.

It's to understand **why** it works, **when** it doesn't, and **how** it can be improved.

Some projects here are polished.

Some are experiments.

Some are evidence that I should have gone to sleep three hours earlier.

All of them taught me something.
